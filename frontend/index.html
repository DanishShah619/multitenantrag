Integration Code Samples (curl)

1. Ingest Document (Admin Key) 
curl -X POST "$BACKEND_URL/documents" \
  -H "X-API-Key: $ADMIN_API_KEY" \
  -F "file=@document.pdf"
2. Streaming Chat Query (Embed Key) 
curl -N -X POST "$BACKEND_URL/chat" \
  -H "X-API-Key: $EMBED_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "What are the payment terms?"}'
